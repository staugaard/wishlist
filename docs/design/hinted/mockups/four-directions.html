Wishlist — four directions

Same family, same five gifts, four identities. Each direction shows its wordmark and palette, the giver's shared page (phone), the owner's home (phone), and the owner's list editor (desktop). Native theme shown; the paired swatch row is the other theme.

01 · Paper & craft
Hinted

A wishlist is really a list of hints. Brown paper, letterpress serif, a dashed tag tied on with string.

Type
Instrument Serif
Karla · body, labels, small caps
Light — default
Dark — evening
Warmth comes from

Paper stock, not gradients. Hairline dashed rules. A hard offset shadow, like a card resting on a table. Ink that is brown-black, never true black.

03 · Evening warmth, dark-first
Wishwell

Built for the couch at nine in the evening. Dark by default, lit by a single amber lamp; the light theme is derived from it, not the other way round.

Type
Bricolage Grotesque
Public Sans · body and UI
Dark — default
Light — daytime
Warmth comes from

Light, literally. One radial glow behind the list header. Priority items are lit rather than badged — a warm rim on the card. Everything else stays unlit and calm.

Ribbon

Type
Petrona Bold
Gabarito · body and UI
Light — default
Dark — evening
Warmth comes from

Saturation and weight. Plum fills the header edge to edge; cards sit on it with a solid ink outline and offset shadow. Playful in shape, grown-up in colour.
