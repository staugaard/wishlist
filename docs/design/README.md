# Design

The chosen direction is **Hinted** — see `hinted/` for the full handoff bundle
(README, tokens, component sources, and full-fidelity mockups).

Provenance: produced by Claude Design in the claude.ai/design project
"Wishlist" (projectId `20d9fe31-f74c-4acd-901b-f6b773e19524`), 2026-08-13.
That project also holds the live component cards, the "Four Directions"
exploration, and interactive templates — sync from there if this copy ever
needs refreshing. The `reference/design-brief.md` mentioned in the handoff
README is this repo's `docs/design-brief.md`.

## Sanctioned deviations

- 2026-08-14 (user decision, from real-list use): the giver page's ItemCard
  renders **no photo element at all** when an item has no image — the dashed
  "no photo" box remains only in the owner's rows/editor, where it holds the
  grid. The handoff's own rule ("a hand-typed item is a completely normal
  item") argued for it.
- Move up/down instead of drag reorder (Phase 2 spec) · PNG favicon instead
  of SVG (Phase 4 spec).
